## 📌 Project Overview

**TrendPulse** is a 4-stage data pipeline project that collects trending stories from the Hacker News API, processes and analyzes the data, and finally visualizes insights through charts and dashboards.

The project is completed in four sequential tasks:

```text
Task 1 → Task 2 → Task 3 → Task 4

Fetch JSON → Clean CSV → NumPy/Pandas Analysis → Visualization
```

Each task uses the output generated by the previous task.

# 🚀 Task 1 — Fetch Data from API

**File:** `task1_data_collection.py`

### Objective

Fetch trending stories from the Hacker News API and categorize them into:

* Technology
* World News
* Sports
* Science
* Entertainment

### API Endpoints

#### Get Top Story IDs

```text
https://hacker-news.firebaseio.com/v0/topstories.json
```

#### Get Story Details

```text
https://hacker-news.firebaseio.com/v0/item/{id}.json
```

### Request Header

```python
headers = {
    "User-Agent": "TrendPulse/1.0"
}
```

### Categories & Keywords

| Category      | Keywords                                                               |
| ------------- | ---------------------------------------------------------------------- |
| technology    | AI, software, tech, code, computer, data, cloud, API, GPU, LLM         |
| worldnews     | war, government, country, president, election, climate, attack, global |
| sports        | NFL, NBA, FIFA, sport, game, team, player, league, championship        |
| science       | research, study, space, physics, biology, discovery, NASA, genome      |
| entertainment | movie, film, music, Netflix, game, book, show, award, streaming        |

### Required Fields

| Output Field | Hacker News Field |
| ------------ | ----------------- |
| post_id      | id                |
| title        | title             |
| category     | assigned category |
| score        | score             |
| num_comments | descendants       |
| author       | by                |
| collected_at | current date/time |

### Requirements

* Fetch first 500 story IDs
* Collect up to 25 stories per category
* Handle failed requests gracefully
* Use `time.sleep(2)` between category loops
* Save output JSON in `data/`
* Create `data/` folder if it doesn't exist

### Expected Output

```text
Collected 122 stories.
Saved to data/trends_20240115.json
```

# 🧹 Task 2 — Clean the Data & Save as CSV

**File:** `task2_data_processing.py`

### Objective

Load the JSON file generated in Task 1, clean the data, and export it as a CSV file.

### Cleaning Steps

#### Remove Duplicates

Remove rows with duplicate:

```text
post_id
```

#### Remove Missing Values

Drop rows where:

```text
post_id
title
score
```

are missing.

#### Fix Data Types

Ensure:

```text
score
num_comments
```

are integers.

#### Remove Low-Quality Stories

Remove stories where:

```text
score < 5
```

#### Clean Titles

Strip extra whitespace from:

```text
title
```

### Output File

```text
data/trends_clean.csv
```

### Expected Output

```text
Loaded 122 stories from data/trends_20240115.json

After removing duplicates: 120
After removing nulls: 118
After removing low scores: 114

Saved 114 rows to data/trends_clean.csv

Stories per category:
  technology      22
  worldnews       24
  sports          21
  science         24
  entertainment   23
```

# 📊 Task 3 — Analysis with Pandas & NumPy

**File:** `task3_analysis.py`

### Objective

Analyze the cleaned dataset using Pandas and NumPy and create additional analytical columns.

### Analysis Requirements

Print:

* First 5 rows
* DataFrame shape
* Average score
* Average comments

### NumPy Statistics

Calculate:

* Mean score
* Median score
* Standard deviation of score
* Maximum score
* Minimum score

### Additional Insights

Find:

* Category with the most stories
* Story with the highest number of comments

### New Columns

| Column     | Formula                    |
| ---------- | -------------------------- |
| engagement | num_comments / (score + 1) |
| is_popular | score > average score      |

### Output File

```text
data/trends_analysed.csv
```
